# Πρόβλημα Παραγωγού-Καταναλωτή (Producer-Consumer Problem)

## Περιγραφή

Ζητείται να γραφεί πρόγραμμα σε γλώσσα C που επιλύει αποτελεσματικά και επιδεικνύει τη λύση στο πρόβλημα του παραγωγού-καταναλωτή (Producer-Consumer problem).

Περισσότερες πληροφορίες για το πρόβλημα: https://en.wikipedia.org/wiki/Producer%E2%80%93consumer_problem

Ο ρόλος των παραγωγών είναι να δημιουργούν δεδομένα που τοποθετούν σε κοινό χώρο μνήμης με συγκεκριμένη χωρητικότητα. Οι καταναλωτές πρέπει να χρησιμοποιούν όλα τα δεδομένα που έχουν δημιουργηθεί.

---

## Ζητούμενες Υλοποιήσεις

Ζητείται να υλοποιηθούν **δύο λύσεις**:

- **Λύση 1:** Δημιουργία δύο ή περισσότερων **νημάτων** για τους παραγωγούς και δύο ή περισσότερων νημάτων για τους καταναλωτές.
- **Λύση 2:** Δημιουργία δύο ή περισσότερων **διεργασιών** για τους παραγωγούς και δύο ή περισσότερων διεργασιών για τους καταναλωτές.

---

## Αλγόριθμος Επίλυσης με Σημαφόρους

### Αρχικοποίηση Σημαφόρων

```c
mutex = 1  // αμοιβαίος αποκλεισμός
full  = 0  // αρχικά όλες οι θέσεις είναι κενές, οπότε full = 0
empty = n  // όλες οι θέσεις είναι κενές, n = μέγεθος buffer
```

### Λύση για τον Παραγωγό

```c
while (true) {
    // produce an item
    wait(empty);
    wait(mutex);
    // place item in buffer
    signal(mutex);
    signal(full);
}
```

### Λύση για τον Καταναλωτή

```c
while (true) {
    wait(full);
    wait(mutex);
    // remove item from buffer
    signal(mutex);
    signal(empty);
    // consume item
}
```
