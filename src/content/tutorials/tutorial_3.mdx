# Producer-Consumer Problem

## Περιγραφή

Υλοποίηση του προβλήματος παραγωγού-καταναλωτή σε γλώσσα C με χρήση σημαφόρων.
Οι παραγωγοί δημιουργούν δεδομένα και τα τοποθετούν σε κοινό χώρο μνήμης συγκεκριμένης χωρητικότητας.
Οι καταναλωτές καταναλώνουν όλα τα δεδομένα που έχουν δημιουργηθεί.

Περισσότερες πληροφορίες: [Wikipedia - Producer-Consumer Problem](https://en.wikipedia.org/wiki/Producer%E2%80%93consumer_problem)

---

## Ζητούμενα

Υλοποίηση **δύο λύσεων**:

1. **Με νήματα (threads)** — δύο ή περισσότερα νήματα για παραγωγούς και δύο ή περισσότερα για καταναλωτές.
2. **Με διεργασίες (processes)** — δύο ή περισσότερες διεργασίες για παραγωγούς και δύο ή περισσότερες για καταναλωτές.

---

## Αλγόριθμος Επίλυσης με Σημαφόρους

### Αρχικοποίηση

```c
mutex = 1  // αμοιβαίος αποκλεισμός
full  = 0  // αρχικά δεν υπάρχουν γεμάτες θέσεις
empty = n  // όλες οι θέσεις είναι κενές (n = μέγεθος buffer)
```

### Παραγωγός

```c
while (true) {
    // παραγωγή δεδομένων
    wait(empty);
    wait(mutex);
    // τοποθέτηση στο buffer
    signal(mutex);
    signal(full);
}
```

### Καταναλωτής

```c
while (true) {
    wait(full);
    wait(mutex);
    // αφαίρεση από το buffer
    signal(mutex);
    signal(empty);
    // κατανάλωση δεδομένων
}
```
